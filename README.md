# FLORA DEL PUERTO — Florería de Autor & Vivero Botánico (Maqueta Breborn)

Maqueta e-commerce interactiva desarrollada para florerías y viveros locales en **Viña del Mar y Valparaíso, Chile**.

- Catálogo filtrable con selector de tamaño (`Estándar` / `Grande +35% Flores`)
- Configurador de **Ramo a Medida** + tarjeta de dedicatoria personalizada
- Carrito lateral interactivo con cálculo de despacho por comuna (V Región) y envío directo a WhatsApp (`+56 9 5682 3670`)

Página creada por [Breborn](https://breborn.cl).
